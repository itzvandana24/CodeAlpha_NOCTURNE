# 🌙 NOCTURNE — The World After Sunset

**A cinematic, multi-page nature photography experience built with HTML, CSS, and JavaScript.**

NOCTURNE is a frontend web development project created as part of my **CodeAlpha Frontend Development Internship**. Inspired by the atmosphere of the world after sunset, the website presents photography through a dark, cinematic visual identity, editorial typography, immersive imagery, and subtle animations.

The project focuses on combining visual storytelling with practical frontend functionality to create a cohesive, responsive browsing experience.

---

## ✨ Project Overview

NOCTURNE is designed as a photography showcase where every page contributes to the same visual narrative.

Instead of presenting images in a conventional gallery layout, the website uses carefully designed sections, spacious layouts, image-led storytelling, and interactive elements to make the experience feel more immersive.

### 🎯 Project Objectives

- Build a complete multi-page website using core frontend technologies.
- Create a consistent visual identity across multiple pages.
- Implement interactive features using vanilla JavaScript.
- Develop responsive layouts for desktop, tablet, and mobile screens.
- Practice reusable CSS, DOM manipulation, event handling, and frontend project organization.
- Apply modern UI design principles to a practical internship project.

---

## 🖥️ Website Pages

### 1. Home — An Introduction to the Night

The homepage introduces the visual identity and atmosphere of NOCTURNE through a sequence of editorial sections.

**Key features:**

- **Hero section:** A cinematic opening with prominent typography and immersive imagery.
- **Introductory section:** Establishes the concept and visual direction of the website.
- **Featured Stories slider:** Showcases selected visual stories through an interactive image slider.
- **Visual Statement:** Uses a nature-inspired background and typography to reinforce the site's atmosphere.
- **Gallery Preview:** Presents a selection of images and provides a pathway to explore the full collection.
- **Call to Action (CTA):** Encourages visitors to continue exploring the photography collection.
- **Consistent footer:** Completes the browsing experience with matching site styling.

### 2. Gallery — Explore the Collection

The Gallery page is the central photography showcase, designed to make browsing and discovering images more engaging.

**Key features:**

- **Category filtering:** Filter images by categories such as Forest, Night, City, and Water.
- **Responsive image grid:** Displays photography in a structured, image-focused layout that adapts to different screen sizes.
- **Pagination:** Organizes the collection into manageable pages, displaying a limited number of images at a time.
- **Interactive lightbox:** Opens selected images in an enlarged viewing interface.
- **Keyboard interactions:** Supports keyboard-based lightbox controls, including Escape to close the overlay.
- **Image counter:** Helps visitors understand their position while navigating the lightbox.
- **Responsive navigation and layout:** Keeps the gallery usable across desktop and mobile devices.

### 3. About — The Story Behind NOCTURNE

The About page communicates the philosophy behind the project through an editorial, photography-led presentation.

**Key features:**

- **Editorial hero:** Introduces the concept with the statement, *“The World After Sunset.”*
- **Storytelling-focused content:** Explores the feeling and perspective behind the photography experience.
- **Typography and imagery:** Combines expressive headings with carefully arranged visual content.
- **Scroll-reveal animations:** Adds subtle movement as visitors explore the page.
- **Consistent design language:** Maintains the same cinematic identity as the Home and Gallery pages.

---

## 🎨 Design Philosophy

The visual direction of NOCTURNE is built around atmosphere, contrast, and simplicity.

Rather than relying on excessive effects, the interface uses photography, restrained colors, typography, and subtle motion to establish its identity.

**Design principles:**

- Dark, cinematic visual direction.
- Nature-inspired photography and imagery.
- Editorial typography and clear visual hierarchy.
- Generous spacing and balanced layouts.
- Subtle transitions and scroll-based reveals.
- Consistent navigation and styling across pages.
- Responsive layouts that prioritize usability.

The goal is to make the photography the focus while keeping the interface intuitive and visually cohesive.

## 📱 Responsive Design

NOCTURNE is designed to provide a consistent experience across different screen sizes.

Responsive styling adapts the layout, navigation, image grid, spacing, and typography to fit smaller screens while preserving the website's visual identity.

The project uses CSS media queries and responsive layout techniques to support desktop, tablet, and mobile viewing.

## 🚀 Getting Started

Follow these steps to run NOCTURNE locally.

### Prerequisites

- A modern web browser.
- A code editor such as Visual Studio Code.
- Git, if you want to clone the repository.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/itzvandana24/CodeAlpha_NOCTURNE.git
```

**2. Navigate to the project directory**

```bash
cd CodeAlpha_NOCTURNE
```

**3. Open the project**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code for local development.

No build step is required for the basic static frontend.
