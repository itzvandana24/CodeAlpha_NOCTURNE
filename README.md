# NOCTURNE — The World After Sunset

*A cinematic photography gallery exploring nature, places, and moments through another lens.*

NOCTURNE is a multi-page photography gallery website inspired by the atmosphere and beauty of the world after sunset. It brings together a curated visual experience with a dark, cinematic aesthetic and a focus on clean layouts, responsive design, and interactive gallery features.

This project is being developed as part of my **CodeAlpha Frontend Development Internship**.

## ✨ Features

- **Cinematic dark theme** — A dark visual style designed to complement photography.
- **Responsive layout** — Designed to adapt to different screen sizes.
- **Multi-page navigation** — Separate pages for the Home, Gallery, and About sections.
- **Photography gallery** — A curated collection organized into categories.
- **Category filtering** — Filter gallery images by categories such as Forest, Night, City, and Water.
- **Pagination** — Navigate through gallery images in manageable groups.
- **Image lightbox** — View selected images in an enlarged overlay.
- **Lightbox navigation** — Move between images and view the image counter.
- **Mobile navigation** — Navigation designed to support smaller screens.

## 🎨 Design Direction

NOCTURNE follows a dark, cinematic design direction inspired by the atmosphere of nature, landscapes, and places after sunset.

The visual experience focuses on:

- Deep, muted backgrounds.
- Photography as the primary visual element.
- Clean typography and editorial-style layouts.
- Responsive presentation across desktop and mobile screens.
- Subtle animations and interactions where appropriate.

## 🚀 Getting Started

To run the project locally:

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser, or use a local development server such as the VS Code Live Server extension.
4. Navigate between the available pages to explore the website.

No build step is required for the current HTML, CSS, and JavaScript setup.
